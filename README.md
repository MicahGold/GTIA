# GTIA Negotiation 🤝

Welcome! This repository hosts a set of static HTML pages that simulate a negotiation between **Geoff Gold** and the medical provider **Intellicorp**. Each page reveals a different angle of the story and how the dispute might be resolved. 💡

## Files 📂

- **index.html** – Introduces the tale and lays out the events leading to an MRI bill dispute. 📝
- **dramatis-personae.html** – Profiles the key characters. 🎭
- **facts.html** – Summarizes the important parameters and costs. 💲
- **rules.html** – Outlines communication rules for the negotiation simulation. 📜
- **misc-analysis.html** – Breaks down expected values under different scenarios. 📊
- **nash.html** – Presents decision matrices and BATNA/ZOPA calculations. 🔢
- **strategy.html** – Provides a negotiation strategy for Steph. 🧠
- **insight.html** – Highlights negotiation insights drawn from the case. 🔍
- **submit.html** – Offers a form to submit proposed settlement terms. ✉️
- **images/** – Contains images referenced by the pages. 🖼️

The site relies on inline CSS and a bit of JavaScript to render tables and charts. It was built as a simple educational project to illustrate game theory concepts and negotiation tactics. 🚀
