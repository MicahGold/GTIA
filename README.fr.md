# Négociation GTIA 🤝

Bienvenue ! Ce dépôt héberge un ensemble de pages HTML statiques qui simulent une négociation entre **Geoff Gold** et le prestataire médical **Intellicorp**. Chaque page révèle un angle différent de l'histoire et la façon dont le différend peut être résolu. 💡

## Fichiers 📂

- **index.html** – Présente l'histoire et les événements menant au litige autour de la facture d'IRM. 📝
- **dramatis-personae.html** – Profil des principaux protagonistes. 🎭
- **facts.html** – Résume les paramètres importants et les coûts. 💲
- **rules.html** – Établit les règles de communication pour la simulation de négociation. 📜
- **misc-analysis.html** – Décompose les valeurs attendues dans différents scénarios. 📊
- **nash.html** – Présente des matrices de décision et des calculs BATNA/ZOPA. 🔢
- **strategy.html** – Propose une stratégie de négociation pour Steph. 🧠
- **insight.html** – Souligne les enseignements tirés de la négociation. 🔍
- **submit.html** – Fournit un formulaire pour soumettre des termes de règlement proposés. ✉️
- **images/** – Contient les images utilisées sur les pages. 🖼️

Le site repose sur du CSS intégré et un peu de JavaScript pour afficher les tableaux et graphiques. Il a été conçu comme un projet éducatif simple pour illustrer les concepts de théorie des jeux et les tactiques de négociation. 🚀
